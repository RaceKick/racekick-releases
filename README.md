# RaceKick downloads

Official Windows installer downloads for RaceKick.

This repository is for installers, release notes and update metadata only. Application source is maintained privately.

No installer has been published yet. Initial beta builds remain drafts until tested.

The planned beta update feed will use explicitly selected beta release metadata rather than GitHub's stable-only `latest` endpoint. Installers will be downloaded only after user action. Existing preferences and driver notes remain local.
