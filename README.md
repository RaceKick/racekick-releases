# RaceKick beta downloads

Windows x64 beta installers and release notes are available under [Releases](https://github.com/RaceKick/racekick-releases/releases).

Download the `RaceKick-Setup-…-Beta.exe` asset from the newest beta release. Run Setup as your normal Windows user. Python is bundled; no separate installation is required. Windows may warn about an unknown publisher because these beta installers are not code signed.

Starting with 0.1.32 Beta, RaceKick checks this repository for newer beta releases and offers **Download & install** in Settings. Installation requires your confirmation. Leave the car before installing. Existing overlay settings, driver tags, notes and uploaded images are retained and backed up before an in-app upgrade.

This repository contains distribution assets and publication automation only. App source remains private. A temporary `release-upload/*` branch may hold pieces of a tested installer while a release is being uploaded; it is removed after successful publication. Use release assets, not transfer branches, to install RaceKick.

Beta testing still requires live Windows/iRacing/OBS acceptance. Report your build number, what happened and steps to reproduce; do not include account credentials or private setup data.
